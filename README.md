# Palette Forge

이미지의 최종 색상 수를 제한하면서 사용자가 지정한 RGB 색상을 팔레트에 정확히 유지하는 브라우저 기반 이미지 변환 프로그램입니다. 이미지와 설정은 서버로 전송하지 않으며 현재 브라우저 메모리에서만 처리됩니다.

## 실행

Node.js 22 이상과 pnpm이 필요합니다.

```bash
pnpm install
pnpm dev
```

터미널에 표시되는 주소(기본값 `http://localhost:3000`)를 브라우저에서 엽니다.

배포용 빌드:

```bash
pnpm build
pnpm start
```

## 사용 순서

1. PNG, JPEG 또는 WebP 이미지 한 장 이상을 불러옵니다.
2. 목록에서 편집할 이미지를 선택하고 밝기·대비·채도·색조를 조절합니다.
3. 최종 색상 수(1~32)를 정합니다.
4. 팔레트 슬롯을 눌러 HEX/RGB 또는 색상 선택기로 고정 색상을 지정합니다. 이미지 내부 스포이드는 슬롯 선택 후 사용할 수 있습니다.
5. 필요하면 슬롯별 가중치(0.1~5)를 바꾸고 **변환 실행**을 누릅니다.
6. 설정을 JSON으로 저장하거나, PNG/JPEG/WebP로 현재 이미지 또는 전체 이미지를 내보냅니다.

설정은 이미지별로 독립적으로 유지됩니다. 설정 JSON을 불러오면 현재 선택된 이미지에만 적용됩니다.

## 이미지 처리 방식

처리 순서는 항상 다음과 같습니다.

```text
원본 이미지 → 밝기/대비/채도/색조 보정 → 팔레트 생성 → 팔레트 색상으로 매핑
```

- 팔레트 생성은 OKLab 공간의 결정론적 k-means를 사용합니다.
- 고정 슬롯은 변경되지 않는 중심으로 유지하고, 나머지 중심만 이미지에서 계산합니다.
- 자동 중심 초기화는 고정 색상과 이미 선택된 중심에서 가장 먼 표본을 순서대로 고르는 방식이라 실행마다 결과가 같습니다.
- 투명도가 0인 픽셀은 팔레트 생성과 고유 RGB 색상 수에서 제외합니다. 나머지 픽셀의 알파 값은 유지합니다.
- 최종 픽셀 매핑은 OKLab 거리 제곱을 슬롯 가중치로 나눈 값이 가장 작은 색상을 선택합니다. 가중치 1은 편향이 없고, 값이 클수록 해당 색상의 매칭 범위가 넓어집니다.
- 가중치는 최종 픽셀 매핑에만 적용되므로 가중치를 바꿔도 자동 팔레트 자체는 흔들리지 않습니다.
- 디더링은 지원하지 않으며 항상 비활성화됩니다.

## 설정 파일

버전 1 JSON이며 최종 색상 수, 고정/자동 슬롯 상태, 슬롯 색상과 가중치, 색 보정, 내보내기 설정, 디더링 비활성 상태를 저장합니다. 이미지 파일 자체는 포함하지 않습니다. 누락 가능한 색 보정·내보내기 값은 프로그램 기본값으로 보완하고, 버전·슬롯 수·색상·가중치·필수 값이 잘못되면 사용자에게 오류를 표시합니다.

## 테스트

```bash
pnpm test
```

인위적인 소형 RGBA 이미지를 사용해 색상 수 상한, 고정 색상 보존, 전체 고정 팔레트, 가중치 효과, 투명 픽셀 제외, 설정 왕복, 결정론, 이미지별 상태 분리 및 잘못된 설정 처리를 검증합니다.

## 현재 제한 사항

- 최종 팔레트에는 설정한 수만큼 슬롯이 항상 존재하지만, 원본에 구분 가능한 색이 적거나 특정 가중치가 매우 큰 경우 실제 결과 픽셀에서 일부 슬롯이 사용되지 않을 수 있습니다. 슬롯 사용을 위해 임의의 픽셀을 칠하지는 않습니다.
- 화면 전체 스포이드는 브라우저의 EyeDropper API가 있을 때만 사용할 수 있습니다. 내부 이미지 스포이드는 항상 제공됩니다.
- 전체 내보내기는 여러 파일을 순서대로 다운로드하므로 브라우저가 다중 다운로드 허용을 요청할 수 있습니다.
- JPEG는 알파 채널을 지원하지 않아 선택한 배경색으로 합성합니다. WebP 알파 지원은 브라우저 인코더 지원 범위를 따릅니다.
